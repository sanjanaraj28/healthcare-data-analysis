# Healthcare Data Analysis

A complete, portfolio-ready data analytics project built on a real-world healthcare admissions dataset — covering data cleaning, exploratory data analysis, SQL analysis, an interactive dashboard, and a written report.

## Project Overview

This project analyzes 55,500 hospital admission records (54,860 after cleaning), spanning May 2019 to May 2024. Each record captures a patient's demographics, medical condition, admission/discharge dates, billing amount, insurance provider, prescribed medication, and diagnostic test outcome.

## Project Objective

To independently explore, clean, and analyze the dataset, and to produce a full analytics deliverable: a reproducible Python EDA pipeline, SQL analysis queries, an interactive single-page dashboard, and a professional Word report — all derived directly from the actual data, with no invented figures.

## Dataset

- **File:** `Data/healthcare_data.csv` (raw), `Data/cleaned_healthcare_data.csv` (cleaned)
- **Rows:** 55,500 raw / 54,860 cleaned
- **Columns:** 15 (raw) — Name, Age, Gender, Blood Type, Medical Condition, Date of Admission, Doctor, Hospital, Insurance Provider, Billing Amount, Room Number, Admission Type, Discharge Date, Medication, Test Results
- **Medical conditions covered:** Arthritis, Asthma, Cancer, Diabetes, Hypertension, Obesity

## Data Cleaning

The EDA script performs the following cleaning steps, in order:
1. Standardizes inconsistent name capitalization to Title Case.
2. Strips whitespace from all text columns.
3. Converts admission/discharge dates from text to proper datetime values.
4. Removes 534 fully duplicated records.
5. Removes 108 records with a negative Billing Amount (invalid charges).
6. Derives `Length of Stay`, `Admission Year`, `Admission Month`, and `Admission Year-Month`.
7. Checks Billing Amount for outliers using the IQR method (none found; no removal needed).

Result: **54,860 clean records** across **19 columns** (15 original + 4 derived).

## Exploratory Data Analysis

`Notebook/healthcare_eda.py` produces 15 charts saved to `Visualization/`, including age and billing distributions, gender/condition/admission-type breakdowns, a monthly admissions trend, an age-group vs. condition heatmap, a numeric correlation heatmap, and a top-10 hospitals chart. All chart titles, axes, and legends are labeled for direct reuse in presentations.

## SQL Analysis

`SQL/healthcare_database.sql` defines the `patients` table schema (with indexes) and documents how to load the cleaned CSV using MySQL, PostgreSQL, or SQLite.

`SQL/healthcare_analysis.sql` contains 20+ queries organized by topic (demographics, medical conditions, admissions/outcomes, financials, hospitals/providers, time trends, medication), using GROUP BY, HAVING, CASE, subqueries, CTEs, and window functions (RANK, ROW_NUMBER, LAG).

## Interactive Dashboard

`Dashboard/healthcare_dashboard.html` is a single, self-contained HTML file (Plotly.js is loaded from a CDN; an internet connection is required for the charts to render). It includes:
- Six KPI cards (Total Patients, Total Billing, Avg. Billing/Patient, Average Age, Avg. Length of Stay, Normal Test Result Rate)
- A medical-condition filter that updates the KPIs and related charts
- Twelve interactive charts with hover tooltips
- A responsive layout for desktop and mobile

## Key Insights

- Patient population is nearly evenly split by gender and by medical condition (each of the 6 conditions represents ~16.5-16.8% of admissions).
- Average billing per admission is **$25,594.63**; total billing across all cleaned records is **~$1.40 billion**.
- Average billing varies by less than 3% across conditions — cost does not appear to be condition-driven in this dataset.
- Admission type is split almost evenly across Elective, Urgent, and Emergency.
- Test results are split almost evenly across Normal, Abnormal, and Inconclusive.
- Average length of stay is **15.5 days**.
- Numeric fields (Age, Billing Amount, Room Number, Length of Stay) show negligible correlation with each other.

## Business/Healthcare Recommendations

- Because billing does not vary meaningfully by condition, confirm whether real-world cost drivers (procedures, complications, length of stay) are being captured, or whether this reflects a standardized charge model.
- Maintain balanced staffing/resourcing across Elective, Urgent, and Emergency admission channels, since none currently dominates volume.
- Monitor the Abnormal/Inconclusive test result rate over time as an early signal, since all conditions are currently close to the same rate.
- Use the dashboard as a recurring reporting tool — refresh the data and re-run the EDA script on a regular cadence.

## How to Run the Project

### 1. Set up the Python environment
```bash
cd "Healthcare Data Analysis"
python3 -m venv .venv
source .venv/bin/activate        # on Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Run the EDA pipeline
```bash
cd Notebook
python healthcare_eda.py
```
This will:
- Load `Data/healthcare_data.csv`
- Clean the data and save `Data/cleaned_healthcare_data.csv`
- Save 15 charts to `Visualization/`
- Print a data-quality and insights summary to the console, and save it to `Data/key_insights_summary.txt`

### 3. Explore the SQL analysis
Load `SQL/healthcare_database.sql` and `SQL/healthcare_analysis.sql` into your SQL engine of choice (MySQL, PostgreSQL, or SQLite), following the load instructions commented in `healthcare_database.sql`.

## Dashboard Instructions

Simply open `Dashboard/healthcare_dashboard.html` in any modern web browser (Chrome, Firefox, Edge, Safari) — double-click the file, or right-click → "Open with" your browser. No server or installation is required. An internet connection is needed the first time, so the Plotly.js charting library can load from its CDN.
